**Closer to Onshape: hover and selection**
- Hovering a point lights only the point, never its edge, with Onshape's marker; on a selected edge the point is solid orange with a soft halo.
- Hover and selection looks now match Onshape in every combination checked so far: points, edges, faces, planes, the origin, mate connectors, sketch entities and dialog fields, alone or on top of a selection.
- Sketch entities, Fillet and other dialog fields, and the Select other list look and behave as in Onshape; sketch menus and plane menus list Onshape's items.

**Faster**
- Assemblies: a click selects on the stored display while the assembly still evaluates, and picking in large assemblies is ready many times sooner.

**Fixed**
- A ring shelled at larger wall heights, chamfers on turned edges, and a bore's rounds at both ends of a ring now build as in Onshape.
- Booleans with copied tools or touching tools build more reliably.

**Closer to Onshape**
- Drawings: views sit where Onshape places them; Escape, styles and the sheet behave as in Onshape.
- Sketch: Insert image › Libraries lists your own images library first.
