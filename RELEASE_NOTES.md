**New name and look**
- The app is now called **Noshape** everywhere you read it: window titles, menus, About, the installers and the update card.
- A new, cleaner logo and app icon.
- On a Mac, a new install puts **Noshape.app** in Applications. An existing install keeps updating in place as before.

**Fixed**
- Lofts paired along smooth multi-piece sections, chamfers next to thread bands, mate connectors on sketch points and offset starts with Opposite direction now build as in Onshape (several community documents now rebuild much further).
- Variable Studio column widths are saved with the document, and resizing a column can be undone.
- Exported Parasolid files of o-rings and swept hoses import into Onshape as they should.

**Closer to Onshape**
- Show code shows the Part Studio's FeatureScript as Onshape writes it, in a docked panel.
- Versions and history: date filters, Compare with base in its own window, Reference manager as in Onshape. Ctrl+Alt+V is no longer a shortcut (Onshape has none).
- Help › System check opens as a page; a folder can open in a second documents window; the appearance editor applies colours as you type.
- Drawings: Edit section, Edit auxiliary view and Edit hatch open Onshape's panels; selection inside views behaves as in Onshape.
- STL export of curved (B-spline) surfaces uses Onshape's triangle grid.

**Faster**
- Shells built by Noshape's own builder wherever possible: snap-hook and bottle documents rebuild up to twice as fast.
- Large patterned cuts and some Boolean steps are several times faster (one test document 13.8 s → 5.6 s); an OCCT fix halves the time of the heaviest document in our tests.
