**Closer to Onshape**
- Number fields: opening the "#" variable or function list no longer moves the rows below the field, and the list looks like Onshape's (rounded corners with the highlighted row running edge to edge, no shadow).
- Drawings: title block lines pick and right-click as in Onshape, a projected view has View orientation, radius dimension menus are in Onshape's order, and auxiliary view labels sit where Onshape puts them.
- Sketches: Use, Pierce, measure and planes accept another sketch's splines, ellipses and conics; sketch patterns draw Onshape's direction line and end like Onshape's.
- Sheet metal: a second flange beside the first ends its bend at the plate, faces are named after the feature that made them, and Frame's 8020 profiles match Onshape's sections.
- Routing curves, parting-line drafts, Boundary surfaces and failed Shells (whole part shown in error) behave as in Onshape.

**Fixed**
- Edges left inside a face by a Boolean (for example an old hole's seam) are no longer shown.
- Several fillets, chamfers, sweeps, holes and offsets that failed now build.

**Faster**
- Switching to a Part Studio tab for the first time is faster: the tab's hover preview no longer rebuilds the whole studio.
- Shell is faster on parts with pockets, and Booleans on tori, revolved and free-form faces are faster.
