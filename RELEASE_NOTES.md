**Faster**
- Opening an assembly shows it at once: its last display is stored in the document and its scene is built off the main thread, so the window never freezes while a large assembly loads.
- Shell on free-form faces is quicker and steadier.

**Fixed**
- Chamfers that failed in the last release (a chamfer on a patterned surface) build again.
- Sweeps of touching sketch regions, drafted Through all cuts, Move boundary on curved surfaces, offset surfaces and 3D fit splines build as in Onshape.
- Fillets that ran past an edge's end, and fillet retries on hard edges, now build.
- Battery Remove, Boundary surface and Wrap no longer leave invalid bodies.

**Closer to Onshape**
- Sheet metal: Recognize, Rip, undersized corner reliefs, sketches on a flat and forms match Onshape.
- Sketch: a constraint glyph takes a click only while lit; centre-point arcs, circle centres and line reach act as in Onshape.
- Feature dialogs match Onshape's current standard library (Feature Studios pin its newest release).
- Documents page: Versions and history opens in place, the documents list filters and searches as in Onshape, and Create version and Merge offer Onshape's options.
- Drawings: notes edit where you double-click, box select previews what it will pick, and view simplification lists Onshape's options; circles seen edge-on are written as arcs.
- Export and import: glTF / GLB (including Draco compression), OBJ and 3MF meshes, DXF / DWG exploded text, IGES compatibility mode and Parasolid 25–27 files match Onshape.
- Assemblies: mass properties on faces, and Insert › Other documents lists release candidates and releases.
