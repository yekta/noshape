**Closer to Onshape**
- Release management as in Onshape: the Release candidate dialog, approvers, pending/rejected marks in the version graph; with managed workflows off in Company settings, release entries disappear as in Onshape.
- Assemblies: the Insert dialog (Esc, ✓, preview edges), screen-size mate connectors and mate axes, parts dragged by the point under the pointer, Section view's hint, the instance list's menus.

- Sketch: Extend previews the extension; Properties' Tab order and Material's Esc as in Onshape.

**Fixed**
- Several fillets, chamfers and lofts now build as Onshape's (variable fillets on tangent edges, hole-rim chamfers, guided lofts, mirrored copies).
- Boolean Subtract with Offset now offsets the tools as it should.
- A Distance between two overlapping circles measures as Onshape does.
- Bend relief on a bend running to the sheet's edge gives Onshape's message.

**Faster**
- Fillets and chamfers built directly (the knife's chamfer about 2× faster), sheet metal flat patterns, Move face on freeform surfaces, and big hole-pattern cuts.
