# Sketch Text tool fonts

Onshape's Text tool font list (live dom/sketch-text-fonts.txt, 32 families,
default Open Sans), from Google Fonts (github.com/google/fonts, `ofl/` and
`apache/`), zstd-compressed (`zstd -19`); unpacked on first use
(`noshape_sketch::text::sketch_file`). Variable fonts (`*-VF`) draw Bold as
their `wght` 700 instance. Noto Sans uses the static files in `../`; Open Sans
the 1.10 files of `../drawing/` (live's sketch text: its glyph segments).

Licences: SIL Open Font License 1.1 (`OFL-<family>.txt`) except Roboto Slab and
Droid Sans Mono (Apache License 2.0, `LICENSE-*.txt`; Droid Sans Mono from the
Android platform sources). "Source Sans Pro" is Source Sans 3 (its renamed
successor, same design).
