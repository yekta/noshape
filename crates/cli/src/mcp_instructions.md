noshape is a local parametric CAD app that works like Onshape. These tools do what a person does in the app; every edit is saved at once as an undoable history entry.

The tool list shows the common tools with short descriptions and their main fields (they accept every field ops_describe lists). The other tools (drawing views, annotations and tables; configurations; patterns, groups, BOM and other assembly tools; analysis; sheet metal tables; versions and branches...) are listed by `ops_list` (with `group`), documented by `ops_describe` and run by `ops_call` {"tool", "args"}. Every tool takes `doc` (a .noshape path; default: the current document) and most take `tab` (a tab name or id; default: the first tab of the kind the tool works on). File paths may start with `~` for the home folder.

Documents: the documents folder is {documents}; the app's documents list shows it (and folders added in the app). `document_create` with a name ("bracket") or no path makes the document there; a full path puts it elsewhere. Its reply's `path` is the file's full path. A file already at that path is an error unless `if_exists` is "open". `document_open` opens an existing document (a bare name is looked up in the documents folder). Later calls use the last created or opened document unless `doc` names another.

Parts are modelled as in the app, with sketches and features, so the result stays editable in the feature list. A FeatureScript custom feature suits geometry that is easier to describe as code: repeated or formula-driven shapes (gears, threads, knurls, many computed holes), shapes reused across parts, or steps that would take dozens of calls. A custom feature's parameters show in its dialog.

Workflow for a part:
1. `document_create` or `document_open` (see Documents).
2. `sketch_create` on `plane:top` / `plane:front` / `plane:right`, a planar face id or `{"query": {query_entities arguments}}` matching one face. Coordinates are sketch-plane (x, y) in workspace units (mm by default). On Top x=X, y=Y; on Front x=X, y=Z; on Right x=Y, y=Z. On a face the sketch axes follow the face and may be turned (the reply's `frame`); `sketch_draw` also takes model points [x, y, z], projected onto the sketch.
3. `sketch_draw` with a tool and its clicks (corner_rectangle [[x1,y1],[x2,y2]], circle [[cx,cy],[rim x, rim y]], line [p0,p1,p2,...] — p0 repeated closes it). It adds the same automatic constraints as the app. Then `sketch_dimension` (value "20 mm" or an expression "#width / 2") and `sketch_constrain`.
   Sketch edit tools: `sketch_trim` / `sketch_extend` / `sketch_split` (clicks on curves), `sketch_fillet` / `sketch_chamfer` (corner point ids), `sketch_offset`, `sketch_mirror`, `sketch_linear_pattern`, `sketch_circular_pattern`, `sketch_transform`, `sketch_text`. Model geometry: `sketch_use` projects edges/faces/vertices/planes into the sketch, `sketch_intersection` adds a face's section; dimensions and constraints also take model edge/vertex/plane ids directly. Imports: `sketch_insert_dxf`, `sketch_insert_image`.
4. The `regions` returned by the sketch tools are profile ids for `feature_add` type `extrude` (params: entities = [region ids], depth = "10 mm", operationType NEW/ADD/REMOVE/INTERSECT, endBound BLIND/THROUGH_ALL/...). `feature_schema` gives any feature's parameters, `feature_types` the list (revolve, sweep, loft, fillet, chamfer, shell, hole, patterns, mirror, booleans, sheet metal...).
5. `query_entities` selects model geometry (faces/edges/vertices, filtered by surface/curve type, normal, edge direction, feature, nearest point); `at` [[x,y,z], ...] returns the entity at each point in one call. Their ids go into selection parameters (e.g. fillet `entities`). `feature_types {"search": "..."}` finds a feature; `feature_schema` says which parameters the dialog shows with the defaults and which values show the others (hidden parameters are ignored).
6. Checking: each edit reply has `feature_status` and `regeneration.failed` (sketch edits: `failed`), the feature errors with Onshape's message (custom FeatureScript features add their `notices` with the stack, and `output`; `featurestudio_monitor` shows a Part Studio's Monitor). `query_parts` (volume, bounding box), `query_mass_properties`, `query_measure`, `render_image` (a PNG of the model).
7. `export_parts` writes STEP, STL, Parasolid, IGES, OBJ, 3MF, glTF...; `history_undo` undoes the last edit.

Variables: `variable_create` adds a #variable (a Variable feature) usable in any expression. Configurations: `config_add_input` (list/checkbox/variable), `config_add_option`, `config_configure` a feature parameter (or "suppressed"), `config_set_value` per configuration, `config_activate` sets the configuration later calls of the session see (queries also take `configuration`).

Assemblies: a new document has "Assembly 1" (`tab_create` adds more; calls use the first unless `tab` names another). `assembly_insert` inserts parts from a Part Studio (part ids from `query_parts`), `assembly_set_state` fixes one, `assembly_entities` gives face/edge ids, and `assembly_mate` (fastened, revolute, slider, planar, cylindrical, pin slot, ball, parallel, tangent, width) joins an entity of each instance. `assembly_list` shows placements, mates and the remaining degrees of freedom; `assembly_interference` finds overlapping parts. A mate offset runs along the mate's Z axis, which follows the first connector (flipped as needed, `flip_primary` in the mate); the moved instance's translation shows which way it went. Part arguments take part names as well as ids.

Drawings: `drawing_create` (template, `suggested_views`), then `drawing_get` lists each view (orientation, bounds) with its drawn edges in sheet millimeters; `drawing_dimension` clicks on those coordinates (an edge, a circle, a vertex) and places the text; `drawing_export` writes PDF (PNG for a picture of the sheet).

Live mode: when the noshape app has the document open, calls run in its window: edits show at once and land on the app's undo stack, and `ui_state` reports the tab shown, the view (camera), the selection in the app (entity, `inst:` or drawing ids) and, in a Part Studio, `window`: the open dialog with each field's text, the focused field, an open list, the feature list; `render_image` with `view` "window" shows the window's view.

Workspace protection: `document_protect` makes the current branch refuse model edits (error code `protected`); edits then go on a branch (`history_create_branch`) merged in with `history_merge`, or after `document_unprotect`.

Values: expressions with units ("25 mm", "1 in", "30 deg", "2 * #t + 1 mm"); a bare number takes the workspace unit. Errors name the parameter at fault and what to change.
