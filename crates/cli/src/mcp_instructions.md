noshape is a local parametric CAD app that works like Onshape. These tools do what a person does in the app; every edit is saved at once as an undoable history entry.

The tool list shows the common tools with short descriptions and their main fields (they accept every field ops_describe lists). The other tools (drawing views, annotations and tables; configurations; patterns, groups, BOM and other assembly tools; analysis; sheet metal tables; versions and branches...) are listed by `ops_list` (with `group`), documented by `ops_describe` and run by `ops_call` {"tool", "args"}. Every tool takes `doc` (a .noshape path; default: the current document) and most take `tab` (a tab name or id; default: the first tab of the kind the tool works on).

Workflow for a part:
1. `document_create` (path to a new .noshape file) or `document_open`. Later calls use that document unless you pass `doc`.
2. `sketch_create` on `plane:top` / `plane:front` / `plane:right` or a planar face id. Coordinates are sketch-plane (x, y) in workspace units (mm by default). On Top x=X, y=Y; on Front x=X, y=Z; on Right x=Y, y=Z. On a face the sketch axes follow the face and may be turned (see the reply's `frame`): give `sketch_draw` model points [x, y, z] instead and they are projected onto the sketch.
3. `sketch_draw` with a tool and its clicks (corner_rectangle [[x1,y1],[x2,y2]], circle [[cx,cy],[rim x, rim y]], line [p0,p1,p2,...] — repeat p0 to close). It adds the same automatic constraints as the app. Then `sketch_dimension` (value "20 mm" or an expression "#width / 2") and `sketch_constrain`.
   Sketch edit tools: `sketch_trim` / `sketch_extend` / `sketch_split` (clicks on curves), `sketch_fillet` / `sketch_chamfer` (corner point ids), `sketch_offset`, `sketch_mirror`, `sketch_linear_pattern`, `sketch_circular_pattern`, `sketch_transform`, `sketch_text`. Model geometry: `sketch_use` projects edges/faces/vertices/planes into the sketch, `sketch_intersection` adds a face's section; dimensions and constraints also take model edge/vertex/plane ids directly. Imports: `sketch_insert_dxf`, `sketch_insert_image`.
4. The `regions` returned by the sketch tools are profile ids for `feature_add` type `extrude` (params: entities = [region ids], depth = "10 mm", operationType NEW/ADD/REMOVE/INTERSECT, endBound BLIND/THROUGH_ALL/...). Call `feature_schema` for any feature's parameters, `feature_types` for the list (revolve, sweep, loft, fillet, chamfer, shell, hole, patterns, mirror, booleans, sheet metal...).
5. Select model geometry with `query_entities` (faces/edges/vertices, filter by surface/curve type, normal, edge direction, feature, nearest point); `at` [[x,y,z], ...] returns the entity at each point in one call. Pass their ids to selection parameters (e.g. fillet `entities`). `feature_types {"search": "..."}` finds a feature; `feature_schema` says which parameters the dialog shows with the defaults and which values show the others (hidden parameters are ignored).
6. Check: each edit reply has `feature_status` and `regeneration.failed` (sketch edits: `failed`), the feature errors with Onshape's message (custom FeatureScript features add their `notices` with the stack, and `output`; `featurestudio_monitor` shows a Part Studio's Monitor). `query_parts` (volume, bounding box: compare with a hand estimate), `query_mass_properties`, `query_measure`, `render_image` (a PNG to look at).
7. `export_parts` writes STEP, STL, Parasolid, IGES, OBJ, 3MF, glTF...; `history_undo` undoes the last edit.

Variables: `variable_create` adds a #variable (a Variable feature) usable in any expression. Configurations: `config_add_input` (list/checkbox/variable), `config_add_option`, `config_configure` a feature parameter (or "suppressed"), `config_set_value` per configuration, `config_activate` to choose the configuration later calls see.

Assemblies: a new document has "Assembly 1" (`tab_create` adds more; calls use the first unless you pass `tab`). `assembly_insert` parts from a Part Studio (part ids from `query_parts`), fix one with `assembly_set_state`, get face/edge ids with `assembly_entities`, then `assembly_mate` (fastened, revolute, slider, planar, cylindrical, pin slot, ball, parallel, tangent, width) between an entity of each instance. `assembly_list` shows placements, mates and the remaining degrees of freedom; `assembly_interference` finds overlapping parts. A mate offset runs along the mate's Z axis, which follows the first connector (flipped as needed, `flip_primary` in the mate): check the moved instance's translation and negate the offset if it went the wrong way. Part arguments take part names as well as ids.

Drawings: `drawing_create` (template, `suggested_views`), then `drawing_get` lists each view (orientation, bounds) with its drawn edges in sheet millimeters; `drawing_dimension` clicks on those coordinates (an edge, a circle, a vertex) and places the text; `drawing_export` writes PDF (PNG to look at the sheet).

Workspace protection: `document_protect` makes the current branch refuse model edits (error code `protected`); work on a branch (`history_create_branch`) and `history_merge` it in, or `document_unprotect`.

Values: expressions with units ("25 mm", "1 in", "30 deg", "2 * #t + 1 mm"); a bare number takes the workspace unit. Errors say which parameter is wrong and why.
