# UI font

Onshape's UI font is Flama (commercial). noshape bundles Roboto, the closest
freely licensed match (see docs/ONSHAPE_UI_SPEC.md section 2.1).

| File | Source | Licence |
|---|---|---|
| Roboto-Regular/Medium/Bold/Italic.ttf | github.com/googlefonts/roboto (v2.138, `src/hinted`) | Apache 2.0, `LICENSE-Roboto.txt` |
| Roboto-LightItalic.ttf (input placeholders: Onshape's `::placeholder` is italic 300) | github.com/googlefonts/roboto (v2.138, `src/hinted`) | Apache 2.0, `LICENSE-Roboto.txt` |
| Roboto-SemiBold.ttf | Roboto v3 (Fontsource static 600 instance, Latin) | SIL OFL 1.1, `OFL-Roboto-SemiBold.txt` |
| Inconsolata-Regular/Bold.ttf (measure values: Onshape's `.measurement-value` is `Inconsolata, Monospace` 14 px / 600, which picks the Bold face) | github.com/googlefonts/Inconsolata (v3.000 release, `fonts_ttf.zip`) | SIL OFL 1.1, `OFL-Inconsolata.txt` |
